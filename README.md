# Data Structures - Graph Algorithms

A Data Structures and Algorithms project focused on the implementation of
important graph algorithms including Dijkstra's Algorithm, Floyd-Warshall
Algorithm, Prim's Algorithm, and Kruskal's Algorithm.

## 📌 Overview

This project demonstrates the practical implementation of fundamental
graph algorithms used for finding shortest paths and constructing
Minimum Spanning Trees (MST).

The project was developed to strengthen understanding of graph data
structures, algorithmic problem solving, greedy algorithms, dynamic
programming, and graph optimization techniques.

The implemented algorithms can be applied to problems related to
computer networks, navigation systems, routing, transportation, and
network optimization.

## 🎯 Objectives

The main objectives of this project are:

- Understand graph data structures
- Implement important graph algorithms
- Solve shortest-path problems
- Find Minimum Spanning Trees
- Understand greedy algorithms
- Understand dynamic programming
- Analyze algorithm complexity
- Compare different approaches to graph problems
- Develop practical problem-solving skills

## ✨ Algorithms Implemented

vertex to all other vertices in a weighted graph with non-negative
edge weights.
